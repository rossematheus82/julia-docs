Manual prático de uso da plataforma

Roteiro operacional com prints reais do ambiente de teste: cadastro, entrada no ambulatório do Júlia, pacientes, LME, geração de processo, correção e repetição de LME de colega.

Todos os dados dos prints são fictícios e foram criados apenas para treinamento.

1. Criar conta e entrar

O usuário acessa a tela inicial, cria a conta quando for primeiro acesso e depois entra com e-mail e senha.

  1. Clique em Criar conta para o primeiro acesso.
  2. Informe e-mail e senha.
  3. Depois, volte para Entrar e acesse normalmente.
  4. Use Esqueceu a senha? quando precisar recuperar o acesso.
Por enquanto, usuários comuns não criam ambulatórios. Eles entram no ambulatório do Júlia usando convite.
Manual Julia Docs

2. Entrar no ambulatório

Depois de criar a conta, o usuário deve entrar no ambulatório existente usando o código informado pela administração.

  1. Abra a tela de entrada no ambulatório.
  2. Digite o código de convite.
  3. Clique em Entrar no ambulatório.
Manual Julia Docs

3. Dashboard

O Dashboard é a tela de acompanhamento do ambulatório.

  • Mostra total de pacientes e LMEs.
  • Destaca renovações próximas.
  • O botão Nova LME inicia um novo processo.
  • O menu lateral leva para Pacientes, LMEs e Configurações.
Manual Julia Docs

4. Cadastrar paciente

Antes de emitir uma LME, cadastre ou localize o paciente.

  1. Entre em Pacientes.
  2. Clique em Novo paciente.
  3. Preencha identificação, CPF, CNS, data de nascimento, dados clínicos, contato e endereço.
  4. Revise peso, altura e responsável legal quando houver.
Manual Julia Docs

5. Preencher paciente com IA

A IA pode acelerar o cadastro a partir de texto copiado do prontuário.

  1. Clique em Preencher com IA.
  2. Cole o texto do prontuário.
  3. Clique em Extrair dados.
  4. Confira todos os campos antes de salvar.
A IA ajuda no preenchimento, mas a responsabilidade de revisar os dados continua sendo do usuário.
Manual Julia Docs

6. Criar uma nova LME

O assistente guia o usuário em etapas.

  1. Clique em Nova LME.
  2. Escolha a doença/protocolo.
  3. Avance para tipo de documento e CID-10.
  4. Selecione paciente, médico e estabelecimento.
  5. Preencha dados do prontuário e revise.
Manual Julia Docs

7. Processo completo vs LME + Receita

Essa escolha define quais documentos serão preenchidos.

OpçãoQuando usar
Processo CompletoPrimeira solicitação ou mudança de medicamento/situação clínica. Gera o conjunto completo.
LME + ReceitaRenovação de tratamento já aprovado. Mais rápido, focado no essencial.
Manual Julia Docs

8. Gerar processo

Depois de criada, a LME abre uma tela de detalhe.

  1. Confira paciente, médico, estabelecimento e CID-10.
  2. Clique em Gerar processo completo.
  3. Use Downloads individuais quando precisar baixar apenas um documento.
  4. Abra o PDF e revise antes de protocolar.
Manual Julia Docs

9. Editar LME com problema

Quando uma LME própria voltar com erro, o criador pode corrigir os campos.

  1. Abra a LME.
  2. Clique em Preencher / Editar campos.
  3. Corrija CID-10, anamnese, medicamentos ou campos específicos.
  4. Clique em Salvar e gerar PDF.
Manual Julia Docs

10. LME feita por outro colega

Uma LME emitida por outro médico não deve ser editada diretamente em seu nome.

  1. Você pode baixar o processo original.
  2. Para emitir em seu nome, clique em Renovar / repetir em meu nome.
  3. A plataforma copia os dados da LME anterior para uma nova LME vinculada ao seu perfil.
Manual Julia Docs

11. Repetir em meu nome

Ao repetir uma LME de colega, escolha o escopo da nova emissão.

  1. Apenas a LME: reaproveita o formulário específico anterior e permite ajustar LME/medicamentos.
  2. LME + formulário específico: use quando exames, critérios ou situação clínica mudaram.
  3. Revise os campos copiados e crie a renovação em seu nome.
Manual Julia Docs

12. Boas práticas para ensinar

  • Buscar paciente antes de cadastrar para evitar duplicidade.
  • Conferir CPF, CNS, nascimento, peso, altura e responsável legal.
  • Conferir perfil médico, CRM/UF e estabelecimento antes de gerar PDF.
  • Usar Processo Completo para primeira solicitação ou mudança clínica; usar LME + Receita para renovações simples.
  • Quando a LME for de colega, repetir em seu nome em vez de editar o documento original.
  • Sair da plataforma ao usar computador compartilhado.
